核心特性

专攻"读懂存量 Schema"这件事

不是又一个 ER 设计工具。它的位置是 review、onboarding、迁移前评估——把已经存在的库讲清楚。

⤴

外键智能推断

命名后缀 + 类型一致 + 索引优先 + 复合前缀兜底，给出 high / medium / low 三档置信度，每条都附"推断理由"，支持逐条接受或拒绝。

⊞

分片表自动合并

识别 orders_0..orders_31 这类按尾号水平分片的同构表，合并为单一逻辑表，避免推断阶段产生分片之间的噪声边。

◉

模块自动着色

按 FK 邻接 + 表名前缀聚类业务模块，四套调色板（鲜艳 / 粉彩 / 大地 / 单色）可切换，跨模块的边自动加重提示。

⊘

纯前端 · 离线可用

没有后端、没有上传、没有 telemetry。DDL 进了浏览器就在浏览器里，源码 100% 开源可审。

▢

单文件分发

一个 er-diagram-viewer.html（~900 KB）打包所有依赖，双击就能跑、可邮件、可 U 盘、可塞 wiki 附件，离线环境照常工作。

⤓

DDL 导出

把你已确认的推断 FK 一键导出为 ALTER TABLE ADD CONSTRAINT 脚本，回写到工程仓库里把缺失的 FK 补完整。还能导出 PNG / SVG 用于评审材料。

三种用法

从粘贴到看图，最多 5 秒

  • 线上版：点击"立即试用"，把 DDL 贴进对话框
  • 单文件：下载 .html，离线/内网/U 盘都能跑
  • 自托管：clone 仓库本地启动，或部署到任何静态服务器

样例 schema 在首屏自动加载，你能立即看到外键推断在做什么。

# 自托管：clone + 启动 dev server
git clone <repo>
cd er-diagram-viewer
bun install
bun run dev

# 构建可静态托管的产物
bun run build      # → ./dist
bun run build:single # → ./dist-single/er-diagram-viewer.html
